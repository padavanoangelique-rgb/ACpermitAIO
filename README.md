# PermitAIO Air

Field + office Shop OS for AC/HVAC contractors — leads, dispatch, jobs,
mechanical permit packets (Palm Beach + Broward), heat load, map routing.
PermitAIO's AC product, attached at permitaio.com/ac.

Duplicated from `proper-ac-shopos` (kept separate and unmodified) as the
starting point for this product — see that repo for Proper Air
Conditioning's own live tool.
